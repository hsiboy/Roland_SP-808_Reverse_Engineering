# Link Plan v3 - first read-only SP-808 HDD experiment

Date: 2026-10-05. Specification only; no patched firmware file or MIDI update package was written. Firmware and IDA are unchanged.

**OBSERVED, mechanical conclusion:** All bytes and target addresses needed to generate this experimental image are present. There is **no remaining generation blocker** for the two checked images. Runtime success/safety is **UNRESOLVED**. An untested runtime risk is not a missing linker input.

## Scope and evidence

The experiment performs original SP early startup, A6 cold initialization (which includes EC IDENTIFY), and at most one ATA READ SECTORS submission for **LBA 0, count 1, destination 5D0000**. It then parks with the inherited interrupt state retained. It never returns to normal SP startup, diagnostics, filesystem mounting/routing, recording, or formatting. It does not provide output/exfiltration. RAM/device-control writes needed for initialization are permitted; media-writing ATA commands are excluded.

**OBSERVED sources:** `firmware/SP8EXall.bin`, `firmware/A6_all.bin`, the byte-verified SP IDA functions, and the latest [Evidence Ledger v11](../SP-808EX_Evidence_Ledger_2026-10-05_v11.md), [Technical Reference v9](../SP-808EX_Observed_Architecture_Technical_Reference_2026-10-05_v9.md), [Hardware Corrections v4](../Roland_SP-808_Hardware_Architecture_Corrections_2026-10-05_v4.md), plus the [latest caller/resource audit handoff](CODEX_HANDOFF_2026-10-05.md). Existing names are navigation aids. Prior handoff uncertainty over MCU-ROM vector compatibility is superseded by the newer documentation's physical A6-on-SP HDD control case.

## Demonstrated integration fixes

1. **OBSERVED differential:** SP 105472 loads 0018 before writing TGR1A/TGR2A. A6 setup writes 0050. Replace that immediate with 0050 so the SP shell cannot overwrite A6's selected compare values after init. Independent necessity of that timing value is UNRESOLVED; preservation of the observed A6 configuration is established.
2. **OBSERVED resource conflict; STRONGLY INFERRED reclaim:** A6 private 4033E6-4033ED overlaps live SP numerical state. Relocate status.word to 4033AE, counter-A.byte to 4033B0, counter-B.byte to 4033B1 and selected_end.long to 4033B2. No unproven 43BF48/43C000 reservation is introduced.

The new boot diversion/fast return/one-shot read are **HYPOTHESIZED experiment control glue**, not additional claims of demonstrated storage fixes. ## Cold execution path and read contract

**OBSERVED stock prefix:** Startup reaches 12590C after 12CD7E early setup; 12590C calls 100A8A. At 125910, replace the four-byte `MOV.W #0081,R0` with `JMP 17E200`. This intercepts before button/diagnostic dispatch, stock storage initialization, filesystem boot and the main scheduling/UI loop. All those later paths are excluded from this experiment.

**HYPOTHESIZED glue, exact control flow:** 17E200 performs the stock cold-start 401001=0 operation displaced from 12593E/125940, then calls 105420. The existing descriptor-zeroing helper 10608E is RAM-only in the inspected body. At 10546E the patched shell calls the cold shim; it clears private bytes then tail-jumps to 17D014. A6 cold init installs the original three handlers through 40020C (selectors 48/A0/B0), performs original descriptor/TPU setup, executes IDENTIFY via its own call to 100A58, and keeps its non-media-writing control-command sequence. The retained source issues EC, E1, E5, EF and 10 on this cold path; v3 does not independently remove or reinterpret those operations.

On return, SP executes the patched TGR1A/TGR2A=0050 writes. The 10547E splice jumps to the existing 105562 register-restore/RTS epilogue, bypassing legacy enumeration, 4003B4/status admission, device polling and normal initialization follow-ons. The shell's R0 is now 0050, so the experiment does **not** interpret R0 as success. It requires 401001==1 and word[40101E]==0. The first check prevents an early A6 init failure from looking successful merely because the SP shell initially cleared the status word.

**OBSERVED calling convention:** 100B2A takes LBA in ER0, count in R1L and buffer as a caller-pushed long at stack offset +24 after its 20-byte save frame and 4-byte return address. The experiment pushes 005D0000, passes ER0=0 / R1L=1 and calls 17D5B2 exactly once. It removes the argument, polls byte[401000] for zero and F0DF & 06 for zero, then checks word[40101E]. It does not invoke the transfer-environment waiter or enter a new critical section. If a flag observation occurs between segments, the park does not disable handlers or stop timers; the quiescence observation does not license a hardware reconfiguration.

**STRONGLY INFERRED data lifetime:** 5D0000-5D01FF is the A6 IDENTIFY scratch and the single read destination. The read deliberately overwrites raw IDENTIFY data after A6 has populated the 401000 geometry/context. No new buffer is selected from an unproven unused-DRAM gap. Since normal filesystem startup never runs, the experiment has no later application cache consumer. Inherited concurrent ownership remains UNRESOLVED and is a cold-run validation risk.

**HYPOTHESIZED observables, no output design:** success park PC=17E24A; identify/init rejection PC=17E24C; read error PC=17E24E. Wait PC range 17E232-17E240 means the command or transfer marker remains active. Failures inside original A6 init may wait in its original loops. No retries or second read are submitted by the glue. A hung completion is a possible test result, not an image-generation blocker. No claim of successful IDENTIFY/read is made before running hardware.
